# CareerAI — помощник по поиску работы

**CareerAI** — веб-приложение и интеллектуальный карьерный помощник для студентов, выпускников, начинающих специалистов и соискателей при смене профессии. Приложение универсально и работает с резюме и вакансиями любых отраслей и специальностей.

---

## Основные возможности

1. **Удобный ввод резюме и импорт вакансий**
   - Загрузка резюме в форматах **PDF**, **DOCX** и **TXT** с извлечением русского и английского текста прямо в браузере (до 5 МБ), либо вставка текста вручную.
   - Импорт описания вакансии несколькими способами:
     - **Текст** — вставка или редактирование описания вручную;
     - **Фото / скриншот** — загрузка до 5 изображений (`JPG`, `PNG`, `WEBP` до 10 МБ), вставка из буфера обмена (`Ctrl+V`) или съёмка с камеры телефона с клиентским сжатием и распознаванием текста через Gemini;
     - **Ссылка** — серверный обработчик `POST /api/vacancy/from-url` для извлечения текста вакансии со страницы.
2. **Анализ соответствия резюме и вакансии**
   - Расчёт процента соответствия (0–100%) по весовой модели: обязательные требования, ключевые слова для ATS, опыт/проекты, образование и языки.
   - Разделение навыков на «Что уже подходит» и «Чего не хватает» с пояснениями.
3. **Улучшение резюме и экспорт документов**
   - Конкретные рекомендации по разделам с учётом стандартов рынка труда и ATS.
   - Готовый улучшенный текст резюме без выдумывания несуществующего опыта.
   - Выгрузка улучшенного резюме и полного отчёта анализа в **PDF** (с поддержкой кириллицы) и **TXT**.
4. **План развития на 4 недели**
   - Персональная программа закрытия до 5 приоритетных пробелов: важность навыка, темы для изучения, формат практики, типы ресурсов без выдуманных ссылок и интерактивный чек-лист по неделям (Недели 1–4) с экспортом в TXT.
5. **Тренажёр собеседования по методу STAR**
   - Генерация 5 профильных и поведенческих вопросов именно под выбранную вакансию и пробелы кандидата.
   - Разбор каждого ответа по критериям **S** (Ситуация), **T** (Задача), **A** (Действие), **R** (Результат), оценка от 1 до 10, пример сильного ответа и итоговое резюме.
6. **Встроенная база знаний**
   - Все запросы к ИИ опираются на единый набор правил (`KNOWLEDGE_BASE`): стандарты резюме hh.kz, требования ATS-фильтров, формулы описания достижений, критерии оценки STAR, этика и защита персональных данных, а также универсальность по профессиям.
   - В интерфейсе доступен сворачиваемый блок «На каких правилах работает ИИ».

## Стек технологий

- **Клиент:** React 19, Vite, TypeScript, Tailwind CSS v4, Lucide React, `pdfjs-dist`, `mammoth`, `jspdf`
- **Сервер:** Node.js (v22+), Express (`server.ts`)
- **ИИ:** Google Gemini API через официальный SDK `@google/genai` (модель `gemini-3.1-flash-lite`), вызывается строго на серверной стороне

---

## Как получить ключ в Google AI Studio

1. Перейдите в [Google AI Studio](https://aistudio.google.com/) и войдите в аккаунт Google.
2. Откройте раздел **Get API key** (или **API keys**) в меню слева.
3. Нажмите **Create API key**, выберите существующий проект Google Cloud или создайте новый.
4. Скопируйте сгенерированный ключ — он понадобится для переменной окружения `GEMINI_API_KEY`.

## Локальный запуск

### 1. Установите зависимости

Требуется **Node.js 20+** (рекомендуется v22+).

```bash
npm install
```

### 2. Настройте переменные окружения

Скопируйте шаблон `.env.example` в файл `.env` в корне проекта и вставьте ваш ключ:

```bash
cp .env.example .env
```

Откройте `.env` и укажите свой ключ:

```env
GEMINI_API_KEY=ваш_ключ_из_google_ai_studio
```

> Файл `.env` добавлен в `.gitignore` и не попадает в репозиторий. Никогда не публикуйте API-ключ в клиентском коде или открытых коммитах.

### 3. Запустите приложение в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

### 4. Сборка и запуск production-версии

```bash
npm run build
npm start
```

### Ключевые модули

- **`server.ts` (серверный модуль Gemini и API):**
  - Инициализирует `GoogleGenAI` только на сервере, используя `process.env.GEMINI_API_KEY`.
  - Перед отправкой резюме в Gemini заменяет email, номера телефонов и ссылки на соцсети на метки `[EMAIL]`, `[ТЕЛЕФОН]` и `[ССЫЛКА]`.
  - Обрабатывает временные сбои `429` и `503` с автоматическими повторами до 3 раз (паузы 3, 6 и 12 секунд) и выполняет 1 дополнительную попытку, если ответ модели не удалось разобрать как JSON.
  - Предоставляет маршруты: `POST /api/analyze`, `POST /api/development-plan`, `POST /api/interview/questions`, `POST /api/interview/evaluate`, `POST /api/interview/summary`, `POST /api/vacancy/from-images`, `POST /api/vacancy/from-url`, `POST /api/feedback`.
- **`src/lib/knowledgeBase.ts`:**
  - Экспортирует текстовую константу `KNOWLEDGE_BASE` (9 тематических разделов с правилами оценки, форматами резюме, ATS, STAR и этикой), которая автоматически добавляется в системный промпт каждого AI-запроса.

## Ограничения прототипа

- **Учебный прототип:** результаты оценки и рекомендации формируются языковой моделью; ИИ может ошибаться, поэтому все формулировки и советы перед откликом на вакансию необходимо проверять самостоятельно.
- **Отсутствие серверного хранения:** тексты резюме и вакансий не сохраняются в базе данных или на диске сервера, а также не записываются в `localStorage` браузера. При обновлении страницы текущая сессия сбрасывается.
- **Обратная связь:** при нажатии 👍 / 👎 на сервер и в Google Форму передаются только название блока, оценка и необязательный текстовый комментарий — без резюме, вакансии и персональных данных.
- **Зависимость от квот Gemini API:** при интенсивной нагрузке возможны задержки ответа (до 20+ секунд с учётом серверных повторов) или временное ограничение по квоте запросов.
- **Ограничения извлечения текста:** отсканированные PDF-резюме без текстового слоя могут не прочитаться автоматически в браузере (в этом случае текст нужно вставить вручную).
